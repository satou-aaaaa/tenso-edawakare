# 転送の枝分かれ（tenso-edawakare）

災害のときのうわさ（デマ）は、転送で木の枝のように広がります。届いた知らせを見て、1人が N 人に転送すると何段目に何人に届くか・合計は何人か・合計が何人をこえるのは何段目か・どこで確かめて止めると何人に届かずにすむかを当てる1日5問の学習ゲーム（防災シリーズ BS10）。正解したら、知らせの札（まだ確かめていない・まちがいと分かった・公式と同じ）を見て「まず確かめる」「止める」「広げてよい」を選びます。総務省・内閣府・気象庁の資料の問題も出ます。「枝分かれを試す」で、何人に転送するか・どこで止めるかを変えて試せます。

遊ぶ: <https://satou-aaaaa.github.io/tenso-edawakare/>

- 核：確かめれば、枝はそこで止まる。1人が3人に転送すると、10段目には 3^10＝59,049人。
- 数え方（ゲームの決まり）：あなたが0段目。k段目に届く人数は N^k、0段目から k段目までの合計は（N^(k+1)−1）÷（N−1）。m段目の人が止めると、その人の先の N＋N^2＋…＋N^(K−m) 人に届きません。
- 枝分かれは、遊びのための単純な決まりで、実測ではありません。本物の転送は、同じ人に重ねて届いたり、転送しない人もいたりするので、こんなにきれいには増えません。問題の知らせは練習のための例で、本物の投稿ではありません。
